Initial release: fixed-width integers (`I8`–`I128`, `U8`–`U128`, and custom widths via `FixedInt.make` / `FixedInt.makeBig`) with strict, checked, wrapping, saturating and overflowing arithmetic; `Wrapping`, `Saturating`, `Checked` and `Overflowing` instances; clamped range types; `Float` type class with `F64`, `F32`, total ordering, `NotNaN` and `Finite`; exact `Ratio` and `Complex` numbers; `num-traits` style type classes, `num-integer` algorithms and numeric ranges.
